# Joblane frontend

React interface for Joblane, with search, filters, bookmarks, account forms, and job management.

```bash
npm ci
npm start
```

Runs at http://localhost:3000 and calls the Spring Boot API at http://localhost:8080.

```bash
npm test -- --watchAll=false
npm run build
```

See the [project README](../README.md) for database setup, registration, authentication, and backend startup.
